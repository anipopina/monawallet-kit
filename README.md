# Webプロジェクト用テンプレート

AIと共同で開発するためのルールを中心にしたテンプレートです。技術スタックやアプリのコードを固定せず、要件に合わせた選定から始められます。

## 使い始め方

1. このテンプレートから新しいリポジトリを作成します。
2. [preferences.md](preferences.md) に個人の定番や好みを記入します。未記入の項目は必要になったときに整理できます。
3. 作りたいもの、対象ユーザー、実行環境や公開先の制約をAIに伝え、技術選定と実装を進めます。
4. 採用した構成や判断理由を [AGENTS.md](AGENTS.md) の「プロジェクト固有ルール」に記録します。
5. アプリの構成ができたら、このREADMEをプロジェクトの概要・起動方法・検証方法・運用上の重要事項に置き換えます。

現時点ではアプリのコードや実行・検証コマンドはありません。コミット・デプロイの扱いはAGENTS.mdの「公開・作業境界」に従います。

## ガイド

- [AGENTS.md](AGENTS.md)：共通開発ルール、開始時の進め方、プロジェクト固有ルール
- [preferences.md](preferences.md)：個人の定番と選定条件
- [skills.md](skills.md)：推奨スキル候補、導入・更新方針、プロジェクト単位での共有方法
- [ui-guidelines.md](ui-guidelines.md)：UI・アクセシビリティ
- [notifications.md](notifications.md)：通知の設計とVue Sonner採用時の仕様
- [assets.md](assets.md)：素材の制作・最適化・ライセンス
