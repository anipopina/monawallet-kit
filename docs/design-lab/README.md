# デザイン案の比較ページ

モーダルのデザインを検討したときの案と比較用ページです。参考資料として残しており、利用者向けのツールとしては整備していません。

```sh
pnpm design-lab   # http://localhost:5180/
```

- 案は [presets.ts](presets.ts) にあります。どれも `--mwk-*` トークンの上書きだけで表現しているので、アプリ側のCSSで `.mwk-root` に同じ値を指定すれば再現できます。
- 採用案（ダークは「夜店・明るい面」、ライトは「夜桜」）が、ライブラリの既定値（[src/vue/styles.css](../../src/vue/styles.css)）です。
- ページ内のPasskeyとチェーンAPIは偽物に差し替えており、実際のウォレットや送金には触れません。
